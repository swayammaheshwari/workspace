# 0002 — Dashboard polish, Import/Paste YAML, and the AI prompt file

**Date:** 2026-11-08

## What was asked

Make the dashboard look genuinely good (not just functional), add the ability to import a script via file upload, and add a reusable AI prompt so new video content can be generated by any AI chat and pasted in directly — with a "Copy AI Prompt" button and a "Paste YAML" modal, both restricted to YAML/JSON (not raw Python).

## What changed

- `index.html` redesigned: gradient background, Inter font, card layout per script, Play/Download buttons with a spinner state, a backdrop-blurred video modal.
- `app.py`: `/api/upload` (file import) and `/api/save_yaml` (paste-and-save) endpoints, both validating content (`class_name`, builder `type` exists in `BUILDERS`) before writing to `videos_script/`.
- `/api/prompt` endpoint serves `prompt.md`'s raw text so the dashboard's "Copy AI Prompt" button can copy it to the clipboard in one click.
- `prompt.md` — a copy-paste prompt instructing an AI to ask the user's topic in **one** message (not a fragmented back-and-forth), pick the right existing builder `type` itself, and output **only** a YAML block — no Python, no multi-turn negotiation, no attempt to invent a new builder (that's explicitly routed back to "ask your coding assistant" rather than having an unverified AI chat generate untested geometry code).

## Why

An earlier version of this prompt (before this iteration) caused a real problem: pasted into an external AI, it dragged the user through four separate rounds of questions and then tried to hand back a half-written, untested Python builder for a brand-new visual concept (an "elephant vs ant" video). The rewritten prompt fixes both: one-message questioning, and a hard rule that only existing builder types get a YAML; anything needing new code stops and says so.
