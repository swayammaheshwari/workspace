If text-only, put key facts as on-screen `Text`/`Title` with no narration dependency.
6. **Any color/style preference?** (default: dark background, bold high-contrast colors like `BLUE`, `YELLOW`, `GREEN`, `RED` for emphasis)

Wait for my answers before generating the script.

## Step 2 — Generate the script with these rules

- Output **one single, complete, runnable Python file** — no partial snippets, no placeholders.
- Use `from manim import *` and define **exactly one `Scene` subclass** per file (unless I ask for multiple).
- Class name should be a clear PascalCase description of the topic (e.g. `GoldenRatioSpiral`, `MontyHallParadox`).
- Structure the `construct()` method in this order, with comments marking each part:
  1. **Hook** (first 2-3 seconds) — the surprising claim or visual, shown immediately. No slow intros.
  2. **Build-up** — construct the visual step by step (shapes, equations, graphs) so the viewer's eye can follow.
  3. **Payoff** — the reveal/conclusion, visually emphasized (color change, scale-up, or a final formula/statement).
- If aspect ratio is vertical, add this at the top of the file (before the class):
  ```python
  config.pixel_width = 1080
  config.pixel_height = 1920
  config.frame_width = 9
  config.frame_height = 16
  ```
- Do not use `MathTex`/`Tex` unless I confirmed LaTeX is installed — use `Text()` with unicode math symbols instead.
- Keep animations varied but purposeful: `Write`, `Create`, `Transform`, `FadeIn`/`FadeOut`, `.animate.shift(...)`, `.animate.scale(...)` — avoid overusing any single one.
- Add `self.wait(n)` pauses at moments meant to let a fact sink in, not just at the end.
- Add a short one-line comment above any non-obvious geometry/math calculation (e.g. why a value is divided by golden ratio).
- No external assets (images/audio files) unless I explicitly provide them — everything should be drawn/generated by the code itself.
- If narration was requested, use this pattern (one script, no separate audio variant):

```python
from manim import *
from manim_voiceover import VoiceoverScene
from manim_voiceover.services.gtts import GTTSService

class MyTopicScene(VoiceoverScene):
    def construct(self):
        self.set_speech_service(GTTSService(lang="en"))
        with self.voiceover(text="Narration line goes here.") as tracker:
            self.play(Create(some_mobject), run_time=tracker.duration)
```
